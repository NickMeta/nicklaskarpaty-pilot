# nicklaskarpaty-pilot

Pilot för nya nicklaskarpaty.com. Testsida, inte den riktiga sajten. Allt är spärrat för sökmotorer.

- `index.html`, `drama-cinematography/`, `post/virtual-production-led-volume-cinematographer/` är piloten i design A.
- Länkar till sidor som inte är byggda än går till nuvarande Wix-sidan.
- `utkast.html` och `a–d-*.html` är de tidigare designutkasten.

## Ändra innehåll

Texter, filmer, loggor och kontaktuppgifter finns i `src/content.py` (och sidtexterna i `src/build.py`).
Bygg om sidorna med `python3 src/build.py` (testadress) eller `python3 src/build.py --live` (riktiga sajten).
